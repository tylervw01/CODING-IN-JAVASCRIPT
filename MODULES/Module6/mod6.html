Section 1: Understanding Errors

  • Errors are part of daily coding life — they help us learn.
  • Natural language errors mirror programming mistakes.
  • Exceptions are special error objects that interrupt normal flow.
  • Some errors don’t throw exceptions but still cause issues.
  • Confidence grows with practice and pattern recognition.

The throw statement and custom errors - continued

Problem:


  Function factorial(n) {
    if (n > 20) {
        throw new RangeError("Max value 20");
    }
    let result = 1;
    for (; n > 1; n--) {
        result = result * n;
    }
    return result;
}

console.log(factorial(20)); // -> 2432902008176640000
console.log(factorial(1000)); // -> Uncaught RangeError: Max value 20

Solution:


  function factorial(n) {
    if (n > 20) {
        throw new RangeError("Max value 20");
    }
    let result = 1;
    for (; n > 1; n--) {
        result = result * n;
    }
    return result;
}

console.log(factorial(20)); // -> 2432902008176640000
console.log(factorial(1000)); // -> Uncaught RangeError: Max value 20

WHAT WAS FIXED...

The main issue with this code is a syntax error in the function declaration. Here's the explanation and fix: The keyword Function is capitalized, but in JavaScript it should be lowercase function This causes a SyntaxError because Function (capital F) is a constructor, not a function declaration.

Section 3: Throwing Custom Errors

Use throw to create your own exceptions:


function factorial(n) {
  if (!Number.isInteger(n)) {
    throw new TypeError("Input must be an integer");
  }
  if (n < 0) {
    throw new RangeError("Input must be non-negative");
  }
  if (n > 20) {
    throw new RangeError("Max value 20");
  }
  if (n === 0 || n === 1) return 1;

  let result = 1;
  for (; n > 1; n--) {
    result *= n;
  }
  return result;
}

console.log(factorial(5));   // → 120
console.log(factorial(0));   // → 1
console.log(factorial(-1));  // → Throws RangeError
console.log(factorial(3.5)); // → Throws TypeError
console.log(factorial(21));  // → Throws RangeError

Debugging & Troubleshooting

  • Use browser dev tools to step through code.
  • Inspect and modify variables during runtime.
  • Use debugger to pause execution.
  • Measure performance with console.time() and console.timeEnd(). 

console.time("loop");
for (let i = 0; i < 1000000; i++) {}
console.timeEnd("loop");
// → loop: 2.345ms
