Module 6: Testing Logic

1. What is a SyntaxError?

An error caused by incorrect code structure, like a missing bracket or typo.

2. What is a ReferenceError?

An error that occurs when trying to access a variable that hasn’t been declared.

3. What is a TypeError?

An error caused by performing an invalid operation on a data type, like calling a method on null.

4. What is a RangeError?

An error triggered when a value is outside the allowed range, like a negative array length.

5. What does try...catch do?

It lets you handle exceptions without crashing the program.

6. What is the purpose of finally in try...catch?

It runs cleanup code regardless of whether an error occurred.

7. How do you throw a custom error?

Use the throw keyword with an Error object or message.

8. What error would this code throw: null.f()?

TypeError – null has no methods.

9. What does debugger do?

It pauses code execution and opens the browser’s debugging tools.

10. How can you measure performance in JavaScript?

Use console.time() and console.timeEnd() to measure execution time.

11. What kind of error is caused by let a = b;?

ReferenceError – b is not defined.

12. Why is input validation important in functions?

It prevents unexpected behavior and allows for custom error handling.

13. What does Number.isInteger() help with?

It checks if a value is a whole number, useful for validating inputs.

14. What happens if you don’t catch an exception?

The program may crash or stop executing further code.

15. What’s the benefit of using custom error messages?

They make debugging easier by clearly describing what went wrong.
