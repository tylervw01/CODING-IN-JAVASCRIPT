What Are Functions?

Functions are reusable blocks of code that perform specific tasks. They help organize code and reduce repetition.

Declaring Functions

Use the function keyword followed by a name and parentheses. 


function greet() {
  console.log("Hello!");
}

Calling Functions

Invoke a function by using its name followed by parentheses.


greet(); // Outputs: Hello!

Local Variables

Variables declared inside a function are local and cannot be accessed outside. 


function showMessage() {
  let message = "Hi!";
  console.log(message);
}

The Return Statement

Use return to send a value back from a function.


function add(a, b) {
  return a + b;
}
console.log(add(2, 3)); // Outputs: 5

Function Parameters

Parameters allow functions to accept input values.


function greetUser(name) {
  return `Hello, ${name}!`;
}

Shadowing

Shadowing occurs when a local variable has the same name as a global one. 


let message = "Global";

function showMessage() {
  let message = "Local";
  console.log(message); // Outputs: Local
}
